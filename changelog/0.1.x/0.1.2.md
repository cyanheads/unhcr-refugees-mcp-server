# 0.1.2 — 2026-10-03

## Added

- **Hosted endpoint** — the README and MCP Registry metadata advertise the public Streamable HTTP endpoint and explain its shared dataframe workspace.

## Changed

- **Tool errors** — framework errors carry a request ID matching server logs and automatically include declared recovery hints; handlers retain contextual hint overrides.
- **Argument recovery** — an integer supplied as `name_contains` is converted to a string, and a fractional `limit` rejection explicitly asks for an integer.
- **Docker dependencies** — use the framework OpenTelemetry installer and remove musl-only bindings from the glibc image.
- **Development checks** — reject unloadable definitions, malformed registry JSON, version mismatches, invalid registry launch settings, and build-time JavaScript in target-platform Docker stages; validate release tags before publication.
- **Repository maintenance** — sync framework guidance and environment examples, exclude environment and registry-token files from Docker builds, and retain safe environment templates in git.
- **CodeQL** — run one job per language with stable analysis categories so fixed alerts can close.

## Fixed

- **Registry launch** — npm entries use `npx` without npm-script arguments; the Streamable HTTP entry fixes `MCP_TRANSPORT_TYPE=http` so it starts the advertised transport.
